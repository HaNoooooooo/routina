# 데이터 파일 안내

- `sentences.json` — Oxford Phrase List(750개 표현, A1~C1)를 파싱한 학습 데이터 (정확히 750개
  항목. PDF에서 들여쓰기로 표시된 하위 예문/관련 표현은 별도 학습 항목으로 세지 않고 각 표현의
  `examples` 배열에 붙임)
- `words.json` — The Oxford 3000(A1~B2, 3308개) + The Oxford 5000의 B2~C1 추가 2000단어
  (2012개)를 합쳐 난이도순(A1→A2→B1→B2→C1)으로 정렬한 학습 데이터 (총 5320개 항목)

원본 PDF 3개(`American_Oxford_3000_by_CEFR_level.pdf`, `American_Oxford_5000_by_CEFR_level.pdf`,
`Oxford Phrase List.pdf`)에서 PyMuPDF로 텍스트를 추출한 뒤 스크립트로 정리한 것. 두 단어 목록은
겹치는 단어가 없는 것으로 확인했다(3000이 기본, 5000의 나머지 2000이 그 위에 추가되는 구조). 한글
뜻은 원본에 없으므로 포함하지 않았고, `english-daily` 스킬이 실행 시점에 직접 번역해서 Notion
Progress DB에 기록한다.

## 형식

```json
// sentences.json
[{ "id": 1, "en": "a few", "level": "A1", "examples": ["a few minutes", "a few times", "a few years"] }]

// words.json
[{ "id": 1, "en": "a, an", "level": "A1" }]
```

- `id`는 1부터 시작하는 정수이며 파일 내 등장 순서(=학습 순서)를 그대로 따른다. `sentences.json`,
  `words.json` 모두 A1→C1 순으로 난이도가 올라간다.
- `level`(CEFR)은 참고용 메타데이터이며 스킬 동작에는 쓰이지 않는다.
- `examples`(sentences.json에만 존재, 선택 필드)는 원본 PDF에서 해당 표현 아래 들여쓰기로 딸려
  있던 사용 예문/관련 표현. 학습 항목 수(750개)에는 포함되지 않고, 참고용 부가 정보로만 붙어있다.
- `sentences.example.json` / `words.example.json`은 형식 예시일 뿐 스킬이 읽는 파일이 아니다.

## 검증 내역 (2026-08-10)

원본 PDF 3개를 다시 독립적으로 추출해서 대조 검증함:
- 헤더/저작권/페이지번호/레벨 표시를 제외한 "내용 라인" 수와 최종 파싱된 항목 수가 정확히
  일치 (미매칭 라인 0개, 3000-단어 파일에서 발생한 2건의 줄바꿈 병합까지 정확히 계산 반영).
- 고유 표제어 수: 3000-단어 파일 2991개(공식 명칭 "3000"에 근접), 추가 2000-단어 파일 1999개
  (공식 명칭 "2000"에 근접) — 동일 단어가 품사/의미별로 여러 번 등재되어 총 항목 수(3308,
  2012)는 이보다 많음.
- `bass1`, `bow1`, `content2`, `minute2`, `pension1`, `recount1` 6개 단어에서 동형이의어
  구분 번호(원본 표기 `bass¹`, `bow¹` 등)가 잘못 남아있던 것을 발견해 제거함.
- 그 외 빈 값, 품사 태그가 단어로 잘못 들어간 경우, 40자 초과 비정상 병합, 저작권 기호 등
  잔존 여부를 전수 스캔했고 추가 이상치는 없음.
- `sentences.json`은 원래 PDF의 들여쓰기를 무시하고 모든 라인(표현+하위 예문)을 개별 항목으로
  세는 바람에 999개로 잘못 집계됐던 것을, PyMuPDF의 좌표(x0) 정보로 들여쓰기 여부를 판별해
  다시 파싱함 — 들여쓰기 안 된 최상위 표현만 750개로 정확히 집계, 하위 예문은 `examples`로
  포함.
